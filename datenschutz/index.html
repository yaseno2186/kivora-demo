Datenschutz

[Platzhalter] Dieser Text kommt vom Unternehmen und wird vor dem Start eingefügt.

Kurz gesagt

Diese Website setzt keine Cookies, nutzt keine Analyse- oder Werbedienste und lädt keine Schriften, Skripte oder Bilder von fremden Servern. Deshalb gibt es auch keinen Cookie-Banner.

sessionStorage

Die Seite merkt sich im sessionStorage Ihres Browsers nur, ob Sie das Laufband oder ein Video angehalten haben. Diese Angabe verlässt Ihr Gerät nicht und wird gelöscht, wenn Sie den Tab schließen.

Kontaktformular

In dieser Demo wird nichts gesendet oder gespeichert. Ohne JavaScript öffnet das Formular Ihr eigenes E-Mail-Programm. Was Sie dort abschicken, erreicht uns als normale E-Mail.
